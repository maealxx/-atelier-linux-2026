* Les principales techniques d'attaque

** Brute force

La technique la plus simple : on essaie *toutes les combinaisons possibles*,
une par une, jusqu'à trouver la bonne.

- ~a~, ~b~, ~c~... ~z~
- ~aa~, ~ab~, ~ac~...
- ~aaa~, ~aab~...

C'est lent, mais avec un bon ordinateur (ou un GPU), ça va très vite :

| Longueur | Caractères utilisés                | Temps estimé        |
|----------+------------------------------------+---------------------|
| 6 car.   | minuscules seulement               | ~3 secondes~        |
| 8 car.   | minuscules + chiffres              | ~7 heures~          |
| 10 car.  | majuscules + minuscules + chiffres | ~8 ans~             |
| 12 car.  | tous caractères                    | ~plusieurs siècles~ |

** Attaque par dictionnaire

Plutôt que toutes les combinaisons, on essaie une liste de mots courants :
noms communs, prénoms, dates, mots de passe connus...

#+begin_tip
Les attaques par dictionnaire réussissent dans *la majorité des cas*,
~Soleil1!~ ne trompe personne.
#+end_tip


* Un exemple de brute force en C

Voici un programme minimaliste qui illustre le principe d'une attaque brute force
sur un code à 4 chiffres :

#+NAME: bruteforce
#+BEGIN_SRC C :results output
#include <stdio.h>

int main() {
    int cible = 1337;
    int essais = 0;

    for (int i = 0; i <= 9999; i++) {
        essais++;
        if (i == cible) {
            printf("Mot de passe trouvé : %04d\n", i);
            printf("Nombre d'essais    : %d\n", essais);
            return 0;
        }
    }
    return 0;
}
#+END_SRC

La meilleure défense reste simple :
un mot de passe long, unique, et stocké dans un gestionnaire.

~P@ssw0rd~, et pourtant bien plus facile à retenir.
