* Tableaux

** Création rapide

Taper ~|col1|col2|col3|~ puis ~TAB~ pour créer le tableau.
Taper ~|-~ puis ~TAB~ pour insérer une ligne de séparation horizontale.

| Raccourci     | Action                         |
|---------------+--------------------------------|
| ~TAB~         | Cellule suivante / nouvelle ligne |
| ~S-TAB~       | Cellule précédente             |
| ~C-c C-c~     | Recalculer / actualiser        |
| ~M-↑/↓~       | Déplacer une ligne             |
| ~M-←/→~       | Déplacer une colonne           |
| ~M-S-↑/↓~     | Supprimer / insérer une ligne  |
| ~M-S-←/→~     | Supprimer / insérer une colonne |

** Exemple avec alignement des colonnes

~<l>~, ~<c>~, ~<r>~ force l'alignement d'une colonne :

| <l>  |  <c>   | <r> |
| Nom  | Prénom | Âge |
|------+--------+-----|
| Alex |  Maé   |  18 |

* Blocs de code (Babel)

** Créer un bloc

Raccourci : ~<s TAB~ puis préciser le langage.

#+BEGIN_EXAMPLE
#+NAME: mon_bloc
#+BEGIN_SRC C :results raw
#include <stdio.h>
int main(){ printf("Hello\n"); }
#+END_SRC
#+END_EXAMPLE

** Options importantes des blocs

| Option          | Effet                                          |
|-----------------+------------------------------------------------|
| ~:results raw~  | Affiche le résultat sans les ~:~ devant        |
| ~:results output~ | Capture le stdout (nécessaire pour print)    |
| ~:eval no~      | Ne pas exécuter ce bloc                        |
| ~:var x=42~     | Définit une variable avec une valeur prédéfinie |
| ~:tangle nom.c~ | Exporte le code vers un fichier externe        |
| ~:session nom~  | Partage un processus entre plusieurs blocs     |

~C-c C-c~ pour compiler et afficher le résultat.

** Exemple : variable prédéfinie et tangle

#+NAME: code2
#+BEGIN_SRC C :var toto=42 :tangle test2.c
#include <stdio.h>
int main(){
  printf("Hello je suis %d\n", toto);
}
#+END_SRC

#+RESULTS: code2
: Hello je suis 42

Pour exporter le code vers le fichier ~.c~ : ~C-c C-v C-t~

* Graphviz (DOT)

** Intégration avec Babel

Spécifier le langage ~dot~ avec les options ~:results file :file nom.png~ pour générer une image :

#+BEGIN_EXAMPLE
#+BEGIN_SRC dot :results file :file mon_graphe.png
digraph {
  a -> b
  b -> c
}
#+END_SRC
#+END_EXAMPLE

** Paramètres de mise en forme des nœuds

#+BEGIN_EXAMPLE
rankdir=TB   (orientation : TB/BT/LR/RL)

A [label="Mon nœud" shape=box style=filled fillcolor=lightblue color=blue]
#+END_EXAMPLE

*Formes disponibles (shape) :*

| Valeur         | Description                        |
|----------------+------------------------------------|
| ~box~          | Rectangle classique                |
| ~circle~       | Cercle                             |
| ~ellipse~      | Ellipse (défaut)                   |
| ~diamond~      | Losange                            |
| ~doublecircle~ | Double cercle (états acceptants)   |
| ~point~        | Point                              |
| ~plaintext~    | Texte sans contour                 |

*Styles disponibles (style) :*

| Valeur    | Description              |
|-----------+--------------------------|
| ~filled~  | Remplissage avec fillcolor |
| ~dashed~  | Contour en tirets        |
| ~dotted~  | Contour en pointillés    |
| ~bold~    | Contour épais            |
| ~rounded~ | Coins arrondis           |

*Styles d'arcs :*

| Valeur   | Description                                  |
|----------+----------------------------------------------|
| ~dashed~ | Tirets                                       |
| ~dotted~ | Pointillés                                   |
| ~bold~   | Trait épais                                  |
| ~invis~  | Invisible (utile pour forcer le layout)      |

** Exemple de graphe simple

#+NAME: affiche1
#+BEGIN_SRC dot :results file :file im2.png
digraph {
  rankdir=BT
  A [label="A" shape=circle style=filled fillcolor=lightblue color=blue]
  B [label="B" shape=circle style=filled fillcolor=lightblue color=blue]
  A -> B [label="arc" color=green style=bold]
}
#+END_SRC

** Générer un graphe depuis du code C

Le code C produit du texte DOT via ~:results output~, puis un bloc ~dot~ le récupère via ~:var~ :

#+BEGIN_EXAMPLE
#+NAME: c1
#+BEGIN_SRC C :results output
#include <stdio.h>
int main(){
  printf("a -> b\n");
  printf("a -> c");
  return 0;
}
#+END_SRC

#+NAME: affiche_graphe
#+BEGIN_SRC dot :results file :file sortie1.png :var contenu=c1
digraph {
  $contenu
}
#+END_SRC
#+END_EXAMPLE

** Réutiliser un bloc avec ~#+CALL~

~#+CALL~ permet d'appeler un bloc nommé comme une fonction, en lui passant des arguments :

#+BEGIN_EXAMPLE
#+CALL: affiche_graphe(c2) :file gv3.png
#+END_EXAMPLE

On peut aussi concaténer plusieurs résultats avec bash puis les passer au graphe :

#+BEGIN_EXAMPLE
#+NAME: concat
#+BEGIN_SRC bash :results output :var txt1=c1 txt2=c2
echo ${txt1} ${txt2}
#+END_SRC

#+NAME: fusion
#+CALL: concat()

#+CALL: affiche_graphe(fusion) :file gv4.png
#+END_EXAMPLE
